## Что изменилось

- После обновления с 0.6.1 работающая маршрутизация автоматически пересоздаётся с правилом обхода Xray для ответов на DNAT-соединения. Без этого установленный код 0.6.2 мог ждать ручного повторного включения маршрутизации или перезагрузки.
- Правила обхода, защиты при недоступном Xray и блокировки IPv6 из 0.6.2 сохранены.

## Проверено

Автоматически проверены генерация правил в обоих режимах IPv6, условие обновления действующей таблицы, синтаксис shell-скриптов и `git diff --check`. Доступность внешних TCP/UDP-пробросов после обновления требует проверки на рабочем устройстве.
