## Что изменилось

- На странице «Обзор» добавлена колонка «Версия»: для неустановленных контейнерных модулей можно выбрать latest или конкретную стабильную версию. Установленный модуль показывает свою версию без возможности переключения.
- В 3xUI добавлена вкладка «Входящие»: ручное открытие TCP/UDP из WAN, сопоставление по тегам, исправление устаревших правил и отдельная таблица оставшихся без входящего правил. Разрешения других правил отображаются без возможности изменения.
- На вкладке «Настройка» 3xUI добавлен ручной выпуск и перевыпуск сертификата через HTTP-01, отображение домена и срока действия. Сертификат сохраняется и подключается к HTTPS панели. Автопродление не создаётся.
- Временный доступ для HTTP-01 очищается при завершении и ошибках, повторная попытка восстанавливает незавершённую операцию. Доступ имеет независимое ограничение по времени.

## Проверено

OpenWrt 25.12.5, NanoPi R5S, aarch64: интерфейс LuCI, загрузка списков версий, установка Caddy 2.10.2-alpine и удаление тестового модуля, тесты входящих правил, ошибки и восстановление выпуска сертификатов без обращения в удостоверяющий центр.

Реальный выпуск Let's Encrypt и подключение полученного сертификата к рабочей панели требуют отдельной проверки: тестовый роутер пока находится за NAT без публичного адреса. Для выпуска домен должен указывать на внешний адрес, а внешний TCP/80 — доходить до NanoPi.

Релиз собран из ветки `codex/3xui-inbounds`. Установка другой версии контейнера выполняется после удаления модуля; удаление по-прежнему удаляет его данные и требует подтверждения.

## Установка

Используйте `luci-app-nanopi-control.apk` и `luci-i18n-nanopi-control-ru.apk` из вложений. Контрольные суммы находятся в `SHA256SUMS`.
